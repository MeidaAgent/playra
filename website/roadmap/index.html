ROADMAP

A clear view of Playra’s progress, current priorities, and plans for the future. Timelines may evolve as development continues.

LIVE

Website & Pioneer Access

  • The public website is available at playra.io.
  • The waitlist registration page is available.
  • The homepage and registration experience are implemented and responsive.
  • Waitlist availability should be verified separately from production account storage.
LIVE

Core Game Systems

  • The game codebase includes farming, crops, buildings, crafting, animals, and fishing interfaces.
  • Inventory, production timers, quests, and progression systems are implemented in code.
  • These systems are not presented as guaranteed market-ready features until server testing confirms them.
LIVE

Beta Testing

  • The closed beta is used to test gameplay, accounts, server stability, and progression.
  • Pioneer feedback helps identify bugs, balance issues, and account or inventory problems.
  • Testing is reported through verified Playra channels before wider access is granted.
  • Beta participation does not guarantee a token, reward, or public release date.
IN TESTING

Trading & Marketplace

  • Marketplace and trading interfaces require stability and validation.
  • Legacy blockchain, withdrawal, deposit, and token behavior are disabled under the Playra environment guard.
  • Listing, pricing, anti-fraud, and transaction safeguards must pass testing before broader use.
  • Do not treat the interface as an active external asset marketplace yet.
IN TESTING

Game Economy

  • Balance resource production, crafting costs, and progression rewards.
  • Review supply, inflation, repeatable activities, and long-term account behavior.
  • Separate gameplay balances from any future external economy.
  • Open economy features gradually only after measured stabilization.
IN TESTING

Public Game Release

  • The Play page uses the Playra game build and account/server integration.
  • Public availability depends on current server configuration and account services.
  • No open-access launch promise is made until stable end-to-end play is verified.
  • Environment checks still require production-server validation.
FUTURE CONSIDERATION

PYRA Economy

  • No PYRA contract, network, token launch, sale, or trading venue is confirmed.
  • PYRA has no active earning, withdrawal, staking, or reward pool.
  • Any future announcement will be made only through verified Playra channels.
  • Unofficial contracts, airdrops, presales, and investment offers must be considered unverified.
PLANNED

Social Play & Community Events

  • Multiplayer visits, cooperative activities, and gifting remain planned scope.
  • Event format and participation rules will be confirmed before launch.
  • Community features are developed only as stable server infrastructure permits.
PLANNED

Android & iOS Experience

  • Continue responsive browser support for common mobile devices.
  • Native Android and iOS applications are planned only if browser support is stable.
  • Cloud progress, account recovery, and notifications require final implementation.
FUTURE

World Expansion & Partnerships

  • Additional islands, environments, and content require an established release pipeline.
  • Creator and platform partnerships will be announced only with verified scope and terms.
  • Partnership and roadmap additions will not be presumed from current development work.
