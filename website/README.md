# Playra — Folder Website (Sebelum Masuk Game)

Folder ini berisi seluruh halaman, tampilan, dan asset untuk **Website Playra**:

## Struktur Folder Website
- **`index.html`** : Halaman Beranda / Landing Page utama Playra.
- **`about/`** : Halaman Tentang Playra (`about/index.html`).
- **`docs/`** : Halaman Dokumentasi dan panduan game (`docs/index.html`).
- **`terms-of-service/`** : Halaman Syarat dan Ketentuan layanan (`terms-of-service/index.html`).
- **`privacy-policy/`** : Halaman Kebijakan Privasi (`privacy-policy/index.html`).
- **`css/`** : File style & Tailwind landing (`tailwind_landing.css`, `styles_landing.css`) serta font pixel (`m5x7.ttf`, `upheavtt.ttf`).
- **`assets/`** : Gambar, logo, ikon blockchain/partner, dan banner web.

---

## Hubungan dengan Game
Pada landing page ini, semua tombol **"Play now"** dan **"Start Farming Free"** mengarahkan pengguna ke:
- **`/play/`** (Folder `play/` dan `src/` yang merupakan game utama).
